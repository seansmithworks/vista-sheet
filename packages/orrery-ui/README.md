# orrery-ui

```sh
npm i orrery-ui
```

Re-exports every Orrery component; today that is Iris. Import from `orrery-ui` and `orrery-ui/styles.css`.

To install a single component instead, use its own package (for example `@orrery-ui/iris`). Docs: [root README](https://github.com/seansmithworks/vista-sheet#readme).
